10.1 Mission: Seq2Seq Data Preparation

  • Create and publish your own Seq2Seq dataset on Hugging Face Hub,
  • then write a short Python script (submit.py) that loads and previews the dataset.
  • You can use any sequence-to-sequence task (not only DNA → amino acid) as long as it follows the required structure.

10.2 Mission Steps (short version)

  1. Create a Hugging Face account and get your access token.
  2. Use Google Colab to:
    • Generate your Seq2Seq dataset (src → tgt)
    • Split it into train, validation, and test
    • Upload it to Hugging Face using push_to_hub()
    • Add a short Dataset Card (README)
  3. Create submit.py (a simple script to load and preview your dataset).
  4. Rename your file following this rule: EB502_studentID_name_date_submit.py ex. EB502_20250001_Alice_20251115_submit.py
  5. Email your submit.py file to haseong@kaist.ac.kr before the deadline (2025/11/24).
  • Email subject: [Seq2Seq-Data] studentID name
  • Attachment: your renamed Python file

10.2.1 Example Schema

{
  "src": "ATGTTTACG",
  "tgt": "MF"
}

DatasetDict({
    train: Dataset({ features: ['src', 'tgt'], num_rows: 240 }),

10.4 Mission Steps (detailed version)

10.4.1 Step 1 — Sign Up for Hugging Face and Set Up Colab Environment

10.4.1.1 1) Create a Hugging Face Account

  1. Go to https://huggingface.co.
  2. Click Sign up → Complete the email verification → Log in.

10.4.1.2 2) Generate an Access Token

  1. In the top-right corner, click your profile → Settings → Access Tokens.

  2. Click New token.

    • Name: EB502_2025_hw1_upload
    • Role: Write

  3. Copy the generated token (it starts with hf_...).

    You’ll need this token later when logging in from Colab.

10.4.1.3 3) Open Google Colab

  1. Go to https://colab.research.google.com.
  2. Click + New Notebook.

10.4.1.4 Install Required Packages

In the first code cell, run:

!pip install -U datasets huggingface_hub torch

10.4.1.5 4) Log In to Hugging Face from Colab

In the next cell, run:

from huggingface_hub import login
login()

When prompted, paste the token you created earlier (hf_xxxxxxxxx...) and press Enter. If you see “Login successful”, you’re ready to continue to Step 2.

10.4.2 Step 2 — Create and Upload Your Dataset to Hugging Face Hub

10.4.2.1 1) Generate a DNA → Amino Acid Dataset

In your Colab notebook, add the following code cell and run it:

from datasets import Dataset, DatasetDict
import random

## Your code

You should see output like:

DatasetDict({
    train: Dataset({
        features: ['src', 'tgt'],
        num_rows: 240
    })
    validation: Dataset({
        features: ['src', 'tgt'],
        num_rows: 60
    })
    test: Dataset({
        features: ['src', 'tgt'],
        num_rows: 60
    })
})

10.4.2.2 2) Upload the Dataset to Hugging Face Hub

Now upload the dataset to your Hugging Face account.

repo_id = "yourname/dna2aa-demo"   # replace 'yourname' with your own HF username
dataset.push_to_hub(repo_id)
  • When you see “Upload successful,” it means the dataset is now live.
  • You can view it at:
https://huggingface.co/datasets/yourname/dna2aa-demo

10.4.2.3 3) Add a Dataset Card (README.md)

To make your dataset clear and well-documented, create a dataset card and upload it together.

from huggingface_hub import HfApi

readme_text = """---
license: MIT
language: [en]
---

# DNA → Amino Acid Translation Dataset

### Description
This dataset contains randomly generated DNA sequences (A, C, G, T)  
and their amino-acid translations using the standard genetic code.  
It is suitable for Seq2Seq learning and translation model training.

### Dataset Structure
- **Fields**
  - `src`: input DNA sequence (string)
  - `tgt`: translated amino acid sequence (string)
- **Splits**
  - `train`, `validation`, `test`

"""

api = HfApi()
api.upload_file(
path_or_fileobj=readme_text.encode("utf-8"),
path_in_repo="README.md",
repo_id=repo_id,
repo_type="dataset"
)
  • Once uploaded, open your dataset page again — you’ll now see a full description and license section.

10.4.2.4 4) Verify the Dataset

Finally, reload the dataset from the Hub to confirm it works:

from datasets import load_dataset
ds = load_dataset("yourname/dna2aa-demo")
print(ds)
print(ds["train"][0])

If you see output similar to:

{'src': 'ATGTTT...', 'tgt': 'MF...'}

10.4.3 Step 3 — Create and Submit submit.py

  • After you have successfully uploaded your dataset to Hugging Face Hub (with your repo ID like yourname/dna2aa-demo),
  • you will now create a short Python file for submission.

10.4.3.1 1) Create a New Colab Notebook

  1. Go to Google Colab → click + New Notebook.
  2. This notebook will only be used to generate your submission file.
  3. Make sure you know your dataset’s repo ID from Step 2 (for example yourname/dna2aa-demo).

10.4.3.2 2) Write the Submission Code

  • Copy the code below into the first code cell in your new notebook.
  • ️ Replace yourname/dna2aa-demo with your own dataset ID.
from datasets import load_dataset, DatasetDict

def get_repo_id() -> str:
    # Return your Hugging Face dataset ID
    return "yourname/dna2aa-demo"

def load_dataset_from_hub(repo_id: str) -> DatasetDict:
    ds = load_dataset(repo_id)
    return ds

def preview_samples(ds: DatasetDict, n: int = 3):
    """Show n sample pairs of src→tgt"""
    return [{"src": ds["train"][i]["src"], "tgt": ds["train"][i]["tgt"]} for i in range(n)]

if __name__ == "__main__":
    repo_id = get_repo_id()
    ds = load_dataset_from_hub(repo_id)
    print(ds)
    print(preview_samples(ds))

10.4.3.3 3) Download the File

  • In Colab, open the Files tab
  • Go to Download –> .py Download
  • The file will be saved to your local computer.

10.4.3.4 4) Rename and Submit

  1. Rename the file using your student ID and name:

    EB502_studentID_name_date_submit.py

    Example: EB502_20250001_Alice_20251110_submit.py

  2. Email your file to the me.

    • Email subject: [Seq2Seq-Data] studentID name
    • Attachment: EB502_20250001_Alice_20251110_submit.py
  • You can test your submission before emailing:
  • simply run python submit.py inside Colab or VS Code and check that it loads your dataset correctly.
