9  Day8 seq2seq with attention

9.1 Attention

  • Attention enhances Seq2Seq models by allowing the decoder to selectively focus on different parts of the input sequence at each decoding step
  • Instead of relying on a fixed-length context vector from the encoder, the decoder computes a dynamic context vector by weighting the encoder’s hidden states based on their relevance to the current decoding step.

9.1.1 Fixed-length Context Vector

  • In traditional Seq2Seq models, the encoder compresses the entire input sequence into a single vector called the context vector, which the decoder uses to generate the output sequence.

\[ c = h_T \quad \text{or} \quad c = f(h_1, h_2, ..., h_T) \]

  • This design introduces several limitations.

  • Information Bottleneck

    • All input information must be compressed into a single vector.
    • For long sequences, important fine-grained details are lost during this compression.

  • Vanishing Context

    • As the sequence length increases, earlier tokens have less influence on the final hidden state.
    • This is linked to the vanishing gradient problem in RNNs.

  • Difficulty in Aligning Input and Output

    • There is no direct alignment between specific input tokens and their corresponding output tokens.
    • The decoder must rely solely on the compressed context, without knowing which part of the input is relevant at each step.

9.1.2 Attention Mechanism

The attention mechanism addresses these issues by dynamically focusing on different parts of the input sequence for each output token.

  • Dynamic Context
    • Instead of relying on a single fixed-length vector, the context vector is dynamically computed by “attending” to specific encoder hidden states.
  • Better Handling of Long Sequences
    • Attention allows the decoder to retrieve relevant information from any part of the input, regardless of sequence length.
  • Alignment Between Input and Output
    • Attention naturally creates alignments, making it easier to map input tokens to corresponding output tokens.

9.1.2.1 Attention types

  1. Bahdanau Attention (Additive Attention): \[ score(h_i, s_t) = v^T * tanh(W_1 * h_i + W_2 * s_t) \]

  2. Luong Attention (Multiplicative/Dot-Product): \[ score(h_i, s_t) = h_i^T * W * s_t \]

  3. Scaled Dot-Product Attention: Transformer \[ score(h_i, s_t) = (h_i^T * s_t) / sqrt(d_k) \]

The attention mechanism solves the fixed-length bottleneck by allowing the decoder to dynamically focus on different parts of the encoder’s output for each generated token.

9.1.2.2 Key Ideas

  • Dynamic Context

    • The context vector ( c_t ) is not fixed.
    • It is computed at each decoding step by taking a weighted sum of all encoder hidden states:

    \[ c_t = \sum_i \alpha_{t,i} h_i \]

  • Attention Weights Each weight ( _{t,i} ) measures the relevance between the current decoder state ( s_t ) (query) and encoder state ( h_i ) (key):

    \[ \alpha_{t,i} = \text{softmax}(s_t^\top h_i) \]

  • Better Handling of Long Sequences

    • The decoder can “attend” to any part of the input regardless of sequence length.

  • Alignment Between Input and Output

    • Attention naturally aligns input and output tokens by highlighting relevant positions in the encoder states.

9.1.4 Attention Mechanism Steps (Dot product attention)

  • Alignment Scores
    • Compute alignment scores between the decoder’s current hidden state and each encoder hidden state.
    • \(h_i\) is the encoder hidden state and \(s_{t-1}\) is the decoder’s hidden state. \[ e_{t,i} = h_i^\top W s_{t-1} \]
  • Attention Weights
    • Normalize alignment scores with softmax to get attention weights. \[ \alpha_{t,i} = \frac{\exp(e_{t,i})}{\sum_{j=1}^{T_x} \exp(e_{t,j})} \]
  • Context Vector
    • Compute the context vector as the weighted sum of encoder hidden states. \[ c_t = \sum_{i=1}^{T_x} \alpha_{t,i} h_i \]
  • Combine Context and Decoder State
    • Use the context vector \(c_t\) and the decoder’s current hidden state to predict the next token.

import numpy as np

# Example encoder outputs (keys and values)
L = 4  # Sequence length
D_h = 5  # Hidden dimension

# Simulated encoder hidden states (Keys and Values)
encoder_outputs = np.random.randn(L, D_h)  # Shape: [L, D_h]

# Example decoder hidden state (Query)
decoder_hidden = np.random.randn(D_h)  # Shape: [D_h]

# Compute Scaled Dot-Product
# Query (1, D_h) @ Keys (L, D_h)^T -> (1, L)
attention_scores = np.dot(decoder_hidden, encoder_outputs.T)  # Shape: [1, L]

# Scale scores by sqrt of hidden dimension
scaled_attention_scores = attention_scores / np.sqrt(D_h)  # Shape: [1, L]

# Compute Attention Weights
# Apply softmax to scaled scores
attention_weights = np.exp(scaled_attention_scores - np.max(scaled_attention_scores))  # Stabilize softmax
attention_weights /= np.sum(attention_weights, axis=-1, keepdims=True)  # Normalize, Shape: [1, L]

# Compute Context Vector
# Attention Weights (1, L) @ Values (L, D_h) -> (1, D_h)
context_vector = np.dot(attention_weights, encoder_outputs)  # Shape: [1, D_h]

# Output
print("Encoder Outputs (Keys and Values):", encoder_outputs)
print("Decoder Hidden State (Query):", decoder_hidden)
print("Attention Scores:", attention_scores)
print("Scaled Attention Scores:", scaled_attention_scores)
print("Attention Weights (Softmax):", attention_weights)

9.1.5 Simulation Data: Protein Sequence Evolution

Objective: Train a Seq2Seq model to learn three different transformation rules simultaneously.

  1. Source Sequences

    • Random amino acid sequences (20 amino acids, length 20)
    • Two motifs inserted at fixed positions:
      • RGD motif at positions 5-7
      • ATL motif at positions 12-14
    • Convert to overlapping 3-mers using sliding window (k=3)

  2. Target Sequences (Transformation Rules)

    Each source k-mer is transformed based on pattern matching:

    Condition Rule Example Type
    Contains “RGD” R→K, G→A “RGD”→“KAD” Point mutation
    Contains “ATL” A→V, T→C “ATL”→“VCL” Point mutation
    Other k-mers Reverse order “ABC”→“CBA” Inversion
  • Motif recognition: Tests attention on specific patterns (RGD/ATL)
  • Substitution: Simple 1:1 character mapping (easier)
  • Inversion: Requires positional understanding (harder, tests cross-attention)

9.1.6 Notation Guide

Throughout this notebook, we use the following notation consistently:

9.1.7 Dimensions

  • B: Batch size - number of sequences processed together
  • S_src (or S): Source sequence length - number of tokens in input sequence
  • S_tgt (or T): Target sequence length - number of tokens in output sequence
  • V: Vocabulary size - total number of unique tokens
  • E: Embedding dimension - size of token embeddings
  • H: Hidden dimension - size of LSTM hidden states
  • 2H: Bidirectional hidden dimension - concatenated forward and backward LSTM states

9.1.8 Common Tensor Shapes

  • Source input: (B, S_src)
  • Target input/output: (B, S_tgt)
  • Embeddings: (B, S, E)
  • Encoder outputs: (B, S_src, 2H) - bidirectional LSTM
  • Decoder hidden state: (B, H) - unidirectional LSTM
  • Logits: (B, S_tgt, V)
  • Attention weights: (B, S_src) - probability distribution over source tokens

import torch
import torch.nn as nn
import torch.nn.functional as F


class DotProductAttention(nn.Module):
    """
    Dot-product attention mechanism for Seq2Seq model.
    
    The query comes from decoder hidden state (dim=H) and keys/values are 
    encoder outputs (dim=2H). We project the query to match encoder dimension.
    
    Args:
        dec_dim (int): Decoder hidden dimension (H)
        enc_dim (int): Encoder output dimension (2H for bidirectional LSTM)
    """
    def __init__(self, dec_dim: int, enc_dim: int):
        super().__init__()
        self.q_proj = nn.Linear(dec_dim, enc_dim, bias=False)  # H -> 2H

    def forward(self, dec_hidden, encoder_outputs, src_mask=None):
        """
        Compute attention weights and context vector.
        
        Args:
            dec_hidden: (B, H) - Current decoder hidden state (query)
            encoder_outputs: (B, S_src, 2H) - Encoder hidden states (keys/values)
            src_mask: (B, S_src) - Optional padding mask (True for valid tokens)
        
        Returns:
            context: (B, 2H) - Weighted sum of encoder outputs
            attn_weights: (B, S_src) - Attention probability distribution
        """
        # Project query to encoder dimension: (B, H) -> (B, 2H) -> (B, 2H, 1)
        q = self.q_proj(dec_hidden).unsqueeze(2)
        
        # Compute attention scores: (B, S_src, 2H) @ (B, 2H, 1) -> (B, S_src, 1) -> (B, S_src)
        scores = torch.bmm(encoder_outputs, q).squeeze(2)

        # Mask out padding tokens (set scores to -inf so softmax gives 0 probability)
        if src_mask is not None:
            scores = scores.masked_fill(~src_mask, float('-inf'))

        # Normalize scores to probabilities: (B, S_src)
        attn_weights = F.softmax(scores, dim=1)
        
        # Compute context vector as weighted sum: (B, 1, S_src) @ (B, S_src, 2H) -> (B, 1, 2H) -> (B, 2H)
        context = torch.bmm(attn_weights.unsqueeze(1), encoder_outputs).squeeze(1)
        
        return context, attn_weights


class Seq2SeqEncoder(nn.Module):
    """
    Bidirectional LSTM encoder for sequence encoding.
    
    Args:
        vocab_size (int): Size of vocabulary (V)
        embedding_dim (int): Dimension of token embeddings (E)
        hidden_dim (int): Hidden dimension for LSTM (H)
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True, bidirectional=True)

    def forward(self, x, lengths):
        """
        Encode input sequences using bidirectional LSTM.
        
        Args:
            x: (B, S_src) - Input token IDs
            lengths: (B,) - Actual lengths of sequences (CPU tensor/list)
        
        Returns:
            encoder_outputs: (B, S_src, 2H) - Concatenated forward/backward hidden states
            (h_cat, c_cat): Tuple of (B, 2H) - Concatenated final states for decoder init
        """
        emb = self.embedding(x)  # (B, S_src, E)
        packed = nn.utils.rnn.pack_padded_sequence(emb, lengths.cpu(), batch_first=True, enforce_sorted=False)
        packed_out, (h, c) = self.lstm(packed)
        enc_out, _ = nn.utils.rnn.pad_packed_sequence(packed_out, batch_first=True)  # (B, S_src, 2H)

        # Concatenate last-layer forward/backward states: (B, 2H)
        h_cat = torch.cat((h[-2], h[-1]), dim=1)
        c_cat = torch.cat((c[-2], c[-1]), dim=1)
        return enc_out, (h_cat, c_cat)


class Seq2SeqDecoderWithAttention(nn.Module):
    """
    LSTM decoder with attention mechanism.
    
    Args:
        vocab_size (int): Size of vocabulary (V)
        embedding_dim (int): Dimension of token embeddings (E)
        hidden_dim (int): Decoder hidden dimension (H); encoder outputs have 2H
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim + 2*hidden_dim, hidden_dim, batch_first=True)
        self.attn = DotProductAttention(dec_dim=hidden_dim, enc_dim=2*hidden_dim)
        self.fc = nn.Linear(hidden_dim + 2*hidden_dim, vocab_size)  # [dec_out; context] -> vocab

    def forward(self, input_token, prev_state, encoder_outputs, src_mask=None):
        """
        Perform single decoding step with attention.
        
        Args:
            input_token: (B,) - Current decoder input token IDs
            prev_state: (h, c) - Previous decoder LSTM state, each (1, B, H)
            encoder_outputs: (B, S_src, 2H) - Encoder hidden states
            src_mask: (B, S_src) - Optional padding mask (True for valid tokens)
        
        Returns:
            logits: (B, V) - Output logits over vocabulary
            state: (h, c) - Updated decoder LSTM state
            attn_w: (B, S_src) - Attention weights for this step
        """
        h_prev, c_prev = prev_state  # each (1, B, H)
        emb = self.embedding(input_token).unsqueeze(1)  # (B, 1, E)

        # Compute attention using current decoder hidden state
        query = h_prev[-1]  # (B, H)
        context, attn_w = self.attn(query, encoder_outputs, src_mask=src_mask)  # (B, 2H), (B, S_src)

        # Concatenate embedding and context for LSTM input
        lstm_in = torch.cat([emb, context.unsqueeze(1)], dim=2)  # (B, 1, E+2H)
        out, (h, c) = self.lstm(lstm_in, (h_prev, c_prev))  # out: (B, 1, H)

        # Combine LSTM output and context for final prediction
        logits = self.fc(torch.cat([out.squeeze(1), context], dim=1))  # (B, V)
        return logits, (h, c), attn_w


class Seq2SeqWithAttention(nn.Module):
    """
    Complete Seq2Seq model with attention mechanism.
    
    Args:
        vocab_size (int): Size of vocabulary (V)
        embedding_dim (int): Dimension of token embeddings (E)
        hidden_dim (int): Hidden dimension (H for decoder, 2H for bidirectional encoder)
    """
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super().__init__()
        self.vocab_size = vocab_size
        self.hidden_dim = hidden_dim
        self.encoder = Seq2SeqEncoder(vocab_size, embedding_dim, hidden_dim)
        self.decoder = Seq2SeqDecoderWithAttention(vocab_size, embedding_dim, hidden_dim)

        # Bridge layers: 2H (encoder) -> H (decoder) for initial decoder states
        self.bridge_h = nn.Linear(2*hidden_dim, hidden_dim)
        self.bridge_c = nn.Linear(2*hidden_dim, hidden_dim)

    def init_decoder_state(self, enc_hc):
        """
        Initialize decoder state from encoder's final state.
        
        Args:
            enc_hc: (h_cat, c_cat) - Encoder final states, each (B, 2H)
        
        Returns:
            (h0, c0): Initial decoder states, each (1, B, H)
        """
        h_cat, c_cat = enc_hc  # each (B, 2H)
        h0 = torch.tanh(self.bridge_h(h_cat)).unsqueeze(0)  # (1, B, H)
        c0 = torch.tanh(self.bridge_c(c_cat)).unsqueeze(0)  # (1, B, H)
        return (h0, c0)

    def forward(self, src, src_lengths, dec_inputs, teacher_forcing_ratio=0.5, src_mask=None):
        """
        Perform full sequence-to-sequence translation.
        
        Args:
            src: (B, S_src) - Source sequence token IDs
            src_lengths: (B,) - Actual lengths of source sequences
            dec_inputs: (B, S_tgt) - Target sequence token IDs (must start with <SOS>)
            teacher_forcing_ratio: Probability of using ground truth vs model prediction
            src_mask: (B, S_src) - Optional padding mask for source
        
        Returns:
            logits: (B, S_tgt, V) - Output logits for each target position
            attn_list: List of (B, S_src) attention weight tensors, length S_tgt-1
        """
        device = src.device
        B, S_tgt = dec_inputs.size()

        # Encode source sequence
        enc_out, enc_hc = self.encoder(src, src_lengths)  # enc_out: (B, S_src, 2H)
        dec_state = self.init_decoder_state(enc_hc)  # (h0, c0)
        outputs = torch.zeros(B, S_tgt, self.vocab_size, device=device)
        attn_list = []

        # First input token is always <SOS>
        inp = dec_inputs[:, 0]

        # Decode step by step
        for t in range(1, S_tgt):
            logits, dec_state, attn_w = self.decoder(inp, dec_state, enc_out, src_mask=src_mask)
            outputs[:, t, :] = logits
            attn_list.append(attn_w)

            # Teacher forcing: use ground truth or model's own prediction
            teacher_force = torch.rand(1, device=device).item() < teacher_forcing_ratio
            inp = dec_inputs[:, t] if teacher_force else logits.argmax(dim=1)

        return outputs, attn_list

            src=src,
            src_lengths=src_lens,   
            dec_inputs=dec_in,
            teacher_forcing_ratio=teacher_forcing_ratio,
            src_mask=src_mask  # Prevent attending to padding tokens
        )  # logits: (B, S_tgt, V)

        # Prepare for loss computation: remove t=0 (<SOS>) position
        # Compare logits[:, 1:, :] with targets[:, 1:]
        B, S_tgt, V = logits.size()
        logits_flat = logits[:, 1:, :].contiguous().view(-1, V)   # (B*(S_tgt-1), V)
        targets_flat = dec_tg[:, 1:].contiguous().view(-1)        # (B*(S_tgt-1),)

        loss = criterion(logits_flat, targets_flat)
        loss.backward()

        # Gradient clipping to prevent exploding gradients (essential for RNNs)
        # Limits the L2 norm of gradients to max_norm
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)

        optimizer.step()

        total_loss += loss.item()
        num_batches += 1

    avg_loss = total_loss / max(1, num_batches)
    print(f"Epoch {epoch}/{epochs} - Loss: {avg_loss:.4f}")

def calculate_accuracy(model, loader, device):
    """
    토큰 단위 정확도 계산
    
    Args:
        model: 학습된 모델
        loader: DataLoader
        device: 디바이스
    
    Returns:
        float: 전체 토큰 중 올바르게 예측한 비율
    """
    model.eval()
    total_correct = 0
    total_tokens = 0
    
    with torch.no_grad():
        for batch in loader:
            src, src_lens, dec_in, dec_tg, dec_lens = batch
            src = src.to(device)
            dec_in = dec_in.to(device)
            dec_tg = dec_tg.to(device)
            src_mask = (src != PAD)
            
            # 추론 모드: teacher forcing 사용 안 함
            logits, _ = model(src, src_lens, dec_in, 
                            teacher_forcing_ratio=0.0, 
                            src_mask=src_mask)
            
            # 예측값 계산
            predictions = logits.argmax(dim=-1)  # (B, T)
            
            # PAD 토큰은 제외하고 정확도 계산
            mask = (dec_tg != PAD)
            correct = (predictions == dec_tg) & mask
            
            total_correct += correct.sum().item()
            total_tokens += mask.sum().item()
    
    return total_correct / total_tokens if total_tokens > 0 else 0.0

def decode_sequence(model, src, src_len, max_len=20):
    """
    Greedy decoding으로 시퀀스 생성
    
    Args:
        model: 학습된 모델
        src: (S,) - 소스 시퀀스
        src_len: int - 실제 길이
        max_len: 최대 생성 길이
    
    Returns:
        output_ids: 생성된 토큰 ID 리스트
        attentions: 각 스텝의 attention weights
    """
    model.eval()
    device = next(model.parameters()).device
    
    with torch.no_grad():
        src = src.unsqueeze(0).to(device)  # (1, S)
        src_len = torch.tensor([src_len])
        src_mask = (src != PAD)
        
        # Encoding
        enc_out, enc_hc = model.encoder(src, src_len)
        dec_state = model.init_decoder_state(enc_hc)
        
        # Decoding
        output_ids = [SOS]
        attentions = []
        
        for _ in range(max_len):
            inp = torch.tensor([output_ids[-1]], device=device)
            logits, dec_state, attn_w = model.decoder(
                inp, dec_state, enc_out, src_mask
            )
            next_id = logits.argmax(dim=1).item()
            output_ids.append(next_id)
            attentions.append(attn_w)
            
            if next_id == EOS:
                break
        
        return output_ids[1:], attentions  # <SOS> 제외

def plot_attention_matrix(attn_matrix, input_tokens, output_tokens, title="Attention Weights"):
    """
    Visualize attention weights as a heatmap.
    
    Args:
        attn_matrix: (S_tgt-1, S_src) - Attention weights for each decoding step
        input_tokens: list[str] - Source tokens (length S_src, no PAD)
        output_tokens: list[str] - Target tokens (length S_tgt-1, no <SOS>)
        title: str - Plot title
    """
    plt.figure(figsize=(10, 8))
    plt.imshow(attn_matrix, aspect="auto")
    plt.colorbar()
    plt.xticks(range(len(input_tokens)), input_tokens, rotation=90)
    plt.yticks(range(len(output_tokens)), output_tokens)
    plt.title(title)
    plt.xlabel("Input Sequence (source k-mers)")
    plt.ylabel("Output Sequence (target tokens)")
    plt.tight_layout()
    plt.show()
