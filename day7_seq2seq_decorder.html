8  Day7 Seq2Seq - Decoder

8.1 Recap

8.2 Decoder

  • The decoder generates the output sequence step-by-step, conditioned on the latent representation provided by the encoder
  • The decoder typically consists of an RNN-based architecture, such as an LSTM or GRU, and operates sequentially.

8.2.1 Embedding Layer (Input layer)

  • Converts input indices (target tokens) into dense vectors.
  • \(x_t​=Embed(y_{t−1​})\)

8.2.2 RNN / LSTM / GRU

  • Generates hidden states based on embeddings and previous hidden states.
  • \(h_t​=f(h_{t−1}​,x_t​)\)

8.2.3 Linear + Softmax Layer (Output layer)

  • Maps the hidden states to the output vocabulary space.
  • Converts raw scores (logits) into probabilities over the vocabulary.

8.2.4 Teacher forcing (training)

  • At each time step, the decoder receives
    • The actual token from the target sequence as input.
    • The hidden states from the previous step (or from the encoder for the first step).
  • Teacher forcing speeds up training but may cause discrepancies during inference

8.3 Loss Function

  • During training, the model learns to maximize the likelihood of the correct target sequence given the input sequence.
  • Minimizing the cross-entropy loss between the predicted distribution and the true target tokens.

\[ \mathcal{L} = -\sum_{t=1}^{T} \log P(y_t^{*} | y_{<t}^{*}, x) \]

  • Where:

  • \(y_t^{*}\) : the ground-truth token at time step t

  • \(y_{<t}^{*}\) : the correct tokens from previous steps

  • x: the input sequence

  • in Teacher Forcing, we use the ground-truth token $ y_{t-1}^{*} $ as the next input:

    • This stabilizes and speeds up training.
    • However, it can cause exposure bias, where the model becomes over-reliant on correct inputs.
구분 수학적 기호 값의 범위 설명
Logit \(z_i\) (-∞, +∞) 모델이 각 클래스에 대해 계산한 “점수”
Softmax Probability p_i = e^{z_i} / sum(e^{z_j}) (0, 1) 실제 예측 확률
Log Probability log(p_i) (-∞, 0) 확률의 로그값, 손실 계산에 사용
Cross-Entropy Loss -log(p_{true}) ≥ 0 정답 클래스 확률의 음의 로그

8.4 Inference Process

During inference (or sequence generation), the decoder produces the output sequence step-by-step
in an autoregressive manner — meaning each predicted token is fed back as input for the next step.

  1. Initialize the decoder state
    • The decoder’s initial hidden state is set to the encoder’s final hidden state:
      [ h_0^{dec} = h_T^{enc} ]
  2. Start with a special <SOS> (start-of-sequence) token
    • This token is used as the first input to signal the beginning of generation.
  3. Iterative decoding
    For each time step ( t ):
    • Compute the new hidden state using the previous hidden state and input token:
      [ h_t = f(h_{t-1}, x_t) ]
    • Generate the output probability distribution over the vocabulary:
      [ P(y_t) = (W_o h_t + b_o) ]
    • Select the next token:
      • Greedy decoding: choose the most probable token
        [ y_t = P(y_t) ]
      • or Beam search / Sampling for more diverse results.
    • Feed the predicted token ( y_t ) back into the decoder as input for the next step.
  4. Termination
    • The generation stops when the model outputs an <EOS> (end-of-sequence) token
      or when a predefined maximum length is reached.

In summary, the decoder generates one token at a time, using its own predictions to continue generating until the end-of-sequence is reached.

import torch
import torch.nn as nn

# Define the Seq2Seq Decoder
class Seq2SeqDecoder(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super(Seq2SeqDecoder, self).__init__()
        self.embedding = nn.Embedding(vocab_size, embedding_dim)
        self.lstm = nn.LSTM(embedding_dim, hidden_dim, batch_first=True)
        self.fc = nn.Linear(hidden_dim, vocab_size)

    def forward(self, input_token, hidden, cell):
        # Embed the input token (shape: [batch_size, 1] -> [batch_size, 1, embedding_dim])
        embedded = self.embedding(input_token)
        
        # Pass through LSTM (input shape: [batch_size, 1, embedding_dim])
        output, (hidden, cell) = self.lstm(embedded, (hidden, cell))
        
        # Predict the next token (shape: [batch_size, vocab_size])
        prediction = self.fc(output.squeeze(1))  # Remove time step dimension
        return prediction, hidden, cell

import torch
import torch.nn as nn
import torch.optim as optim
import numpy as np
from torch.utils.data import DataLoader

# Define Seq2Seq model
class Seq2Seq(nn.Module):
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        super(Seq2Seq, self).__init__()
        self.encoder = Seq2SeqEncoder(vocab_size, embedding_dim, hidden_dim)
        self.decoder = Seq2SeqDecoder(vocab_size, embedding_dim, hidden_dim)

    def forward(self, src, src_lengths, tgt, teacher_forcing_ratio=0.5):
        # Encode the source sequence
        hidden, cell = self.encoder(src, src_lengths)
        
        # Initialize decoder input (start token, e.g., the first token in tgt)
        batch_size = tgt.size(0)
        tgt_length = tgt.size(1)
        outputs = torch.zeros(batch_size, tgt_length, vocab_size).to(src.device)

        input_token = tgt[:, 0]  # The first input to the decoder

        for t in range(1, tgt_length):
            # Decode one step
            output, hidden, cell = self.decoder(input_token.unsqueeze(1), hidden, cell)
            outputs[:, t, :] = output  # Store output for this time step

            # Decide whether to use teacher forcing
            teacher_force = torch.rand(1).item() < teacher_forcing_ratio
            input_token = tgt[:, t] if teacher_force else output.argmax(1)

        return outputs
