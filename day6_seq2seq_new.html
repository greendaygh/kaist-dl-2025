7.1 Why Do We Need Seq2Seq?

  • Deep learning models input output comparison
Task Type Input Output Example
Classification Fixed vector Class Protein function prediction
Regression Fixed vector Numeric value Enzyme activity prediction
Seq2Seq (Translation) Sequence (variable length) Sequence (variable length) Sentence translation / DNA → Protein translation**
  • Key difference is both input and output are sequences, and their lengths may differ.

Example:
“I am a student.” → “나는 학생이다.”

  • Input and output lengths differ
  • Word order and syntax vary across languages.
  • The model must not only align words but also understand the context to produce a meaningful new sentence.
  • This process of reading one sequence and generating another is the core idea of sequence-to-sequence translation.

Example: Biological Translation: DNA → Protein

DNA: ATG GAA TTC GGG TGA
       ↓   ↓   ↓   ↓
AA :   M   E   F   G   (STOP)
Input (DNA) Output (Protein) Relationship
A, T, G, C 20 amino acids 3 bases → 1 amino acid

biological translation is a natural example of a Seq2Seq problem
(input: nucleotide sequence, output: amino acid sequence).

7.2 Problem Formulation

  • Given an input sequence, the goal is to generate an output sequence

X = (x₁, x₂, …, x_T),

Y = (y₁, y₂, …, y_{T′}).

The model maximizes the conditional probability:

\[ P(Y|X) = ∏ₜ P(yₜ | y₍₁:ₜ₋₁₎, X) \]

y₍₁:ₜ₋₁₎: previously generated tokens (words or amino acids)
X: the full input sequence (sentence or DNA bases)

  • Chain rule: P(y₁, y₂, y₃) = P(y₁)·P(y₂ | y₁)·P(y₃ | y₁, y₂)

P(Y | X) = P(y₁, y₂, …, y_T′ | X)

P(Y | X) = P(y₁ | X)·P(y₂ | y₁, X)·P(y₃ | y₁, y₂, X)…P(y_T′ | y₁, …, y_T′₋₁, X)

  • When predicting the next word (or amino acid), the model considers both the previous outputs and the full input context.

  • A simple RNN classifier assumes a fixed one-shot output, while Seq2Seq tasks require variable-length, step-by-step conditional generation.

    • Simple RNN Classifier: Many-to-one
    • Seq2seq approach: Many-to-many

  • Hence, we need an Encoder–Decoder architecture with autoregressive decoding and attention.

    • Encoder: Compresses the input sequence into a semantic vector (context).
    • Decoder: Generates the output sequence step by step based on the context.

7.3 Encoder Components

7.3.0.1 Embedding Layer

  • Converts input token indices into dense, continuous vector representations.
  • Allows the model to represent discrete tokens (e.g., words, characters) in a meaningful way for further processing.

7.3.0.2 Recurrent Neural Network (RNN)

  • Processes the embeddings sequentially and captures temporal dependencies.

  • Variants include:

    • Simple RNN: Basic recurrent unit.
    • LSTM (Long Short-Term Memory): Handles long-term dependencies.
    • GRU (Gated Recurrent Unit): A simplified version of LSTM.

7.3.0.3 Context Vector

  • The final hidden state (or all hidden states) of the RNN represents the input sequence context.
  • Passed to the decoder for generating output.

7.4 Embedding Layer

  • An embedding layer is used to represent discrete categorical data (sparse one-hot matrix) as dense, continuous vectors.

  • Dimensionality Reduction

    • Instead of representing a word or token as a large sparse vector (e.g., one-hot encoding), embeddings map them to a smaller, dense vector space.
    • One-hot vector for a vocabulary of 10,000 words: [0, 0, ..., 1, 0] (10,000 dimensions).
    • Embedding vector: [0.5, ..., -0.2, 0.1] (e.g., 512 dimensions).

  • Captures Semantic Relationships

    • Similar words or tokens are mapped to similar embeddings in the vector space.
    • “king” and “queen” might be close in embedding space, capturing semantic similarity.

  • Efficient Computation

    • Dense vectors are smaller and faster to process compared to sparse representations like one-hot encoding.

7.4.0.1 Types

  • k-mer Encoding
    • Used for DNA/RNA sequences by splitting into overlapping k-length substrings.
    • Sequence: "ACGTAC"
    • 3-mer: ["ACG", "CGT", "GTA", "TAC"]
  • Label Encoding
    • Maps each k-mer to a unique integer.
    • Encoding: {"ACG": 0, "CGT": 1, "GTA": 2}
  • One-Hot Encoding
    • Represents nucleotides (e.g., A, C, G, T) as binary vectors.
    • A → [1, 0, 0, 0]
  • Embedding
    • Converts nucleotides, k-mers, or amino acids into dense vectors.
    • A → [0.3, 0.7, -0.1]

7.4.1 Word2Vec

  • It generates word embeddings dense vector representations of words that capture their meanings and relationships.
  • Unlike traditional representations (e.g., one-hot encoding), Word2Vec places words with similar meanings closer together in a high-dimensional vector space, enabling models to understand semantic and syntactic relationships between words.
  • References
    • Mikolov, Tomas, et al. “Efficient estimation of word representations in vector space.” arXiv preprint arXiv:1301.3781 (2013) [Citations: 50170]
    • Mikolov, Tomas, et al. “Distributed representations of words and phrases and their compositionality.” Advances in neural information processing systems 26 (2013) [Citations: 48860]

7.4.1.1 Data

  • Skip-gram model: the input is the center word (target), the output is one of its surrounding words (context)
  • The model learns to predict which context words are likely to appear around a given target word
  • It captures co-occurrence relationships
  • Through this training, words that share similar contexts end up having similar vector representations.

class SkipGramSoftmax(nn.Module):
    def __init__(self, vocab_size, emb_dim, init_std=0.05):
        super().__init__()
        self.in_emb = nn.Embedding(vocab_size, emb_dim)            # W_in: (V, D)
        self.out_lin = nn.Linear(emb_dim, vocab_size, bias=False)  # W_out: (D, V)
        nn.init.normal_(self.in_emb.weight, mean=0.0, std=init_std)
        nn.init.normal_(self.out_lin.weight, mean=0.0, std=init_std)

    def forward(self, T):
        H = self.in_emb(T)                 # (B, D)
        logits = self.out_lin(H)           # (B, V)
        log_probs = F.log_softmax(logits, dim=1)
        return log_probs                   # (B, V)

model = SkipGramSoftmax(V, emb_dim).to(device)
optimizer = torch.optim.Adam(model.parameters(), lr=lr)
  • The factor * 0.05 scales down the random weights so that they start with small values.
    • np.random.randn samples with 0 mean 1 sd, which generate samples with range of -3 ~ 3
    • This makes instability and exploding gradients during early training, especially when using functions like softmax or exp.
    • 0.05 ensures a stable initialization (small enough to keep the model’s outputs and gradients within a safe range)
  • log softmax
def log_softmax(x, axis=-1):
    # stable log-softmax (prevent overflow, underflow)
    x_max = np.max(x, axis=axis, keepdims=True)
    z = x - x_max # this makes z are all negative which prevent overflow
    logsumexp = np.log(np.sum(np.exp(z), axis=axis, keepdims=True))
    return z - logsumexp  # log softmax

7.5 Recurrent Neural Network

  • An RNN is a type of neural network designed for sequence data, where the order of inputs matters.
  • Unlike feedforward networks, RNNs have a hidden state that carries information across time steps, enabling them to model dependencies in sequences.

def simple_rnn_step(x, h_prev, W_x, W_h, b):
    return np.tanh(np.dot(x, W_x) + np.dot(h_prev, W_h) + b)

import numpy as np

# Define the encoder class
class Encoder:
    def __init__(self, vocab_size, embedding_dim, hidden_dim):
        self.embedding_dim = embedding_dim
        self.hidden_dim = hidden_dim

        # Initialize weights
        self.embeddings = np.random.randn(vocab_size, embedding_dim)
        self.W_xh = np.random.randn(embedding_dim, hidden_dim)
        self.W_hh = np.random.randn(hidden_dim, hidden_dim)
        self.b_h = np.random.randn(hidden_dim)

    def forward(self, sequence):
        hidden_states = []
        h_prev = np.zeros(self.hidden_dim)  # Initial hidden state
        for idx in sequence:
            x_emb = self.embeddings[idx]  # Get the embedding for the current input
            h_t = np.tanh(np.dot(x_emb, self.W_xh) + np.dot(h_prev, self.W_hh) + self.b_h)  # Compute new hidden state
            hidden_states.append(h_t)
            h_prev = h_t  # Update the previous hidden state
        return np.array(hidden_states)


# Initialize encoder
