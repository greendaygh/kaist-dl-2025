8  Day7 Seq2Seq Decoder

8.1 Recap

8.2 Training

  • The decoder generates the output sequence step-by-step, conditioned on the latent representation provided by the encoder
  • The decoder typically consists of an RNN-based architecture, such as an LSTM or GRU, and operates sequentially.

8.2.1 Embedding Layer (Input layer)

  • Converts input indices (target tokens) into dense vectors.
  • \(x_t​=Embed(y_{t−1​})\)

8.2.2 RNN / LSTM / GRU

  • Generates hidden states based on embeddings and previous hidden states.
  • \(h_t​=f(h_{t−1}​,x_t​)\)
  • \(h_t​=tanh(W_{x} ​x_t​ + W_{h} ​h_{t−1​}+b_h​)\)

8.2.3 Linear + Softmax Layer (Output layer)

  • Maps the hidden states to the output vocabulary space.
  • \(z_t​=W_o ​h_t​+b_o\)​
  • \(z_t = \{z_1, z_2, ..., z_i, ... z_T\}\)
  • Converts raw scores (logits) into probabilities over the vocabulary.
  • \(P(y_t​)=softmax(z_t​)\)
  • \(p_i\) is the i-th element of P(y_t)

8.2.4 Teacher forcing (training)

  • At each time step, the decoder receives
    • The actual token from the target sequence as input.
    • The hidden states from the previous step (or from the encoder for the first step).
  • This stabilizes and speeds up training.
  • However, it can cause exposure bias, where the model becomes over-reliant on correct inputs.

8.3 Loss Function

  • During training, the model learns to maximize the likelihood of the correct target sequence given the input sequence.
  • Minimizing the cross-entropy loss between the predicted distribution and the true target tokens.

\[ \mathcal{L} = -\sum_{t=1}^{T} \log P(y_t^{*} | y_{t-1}^{*}, x) \]

Where:

  • \(y_t^{*}\) : the ground-truth token at time step t

  • \(y_{t-1}^{*}\) : the correct tokens from previous steps

  • \(x\): the input sequence

  • in Teacher Forcing, we use the ground-truth token as the next input:

구분 수학적 기호 값의 범위 설명
Logit \(z_i\) (-∞, +∞) 모델이 각 클래스에 대해 계산한 “점수”
Softmax Probability \(p_i = e^{z_i} / sum(e^{z_j})\) (0, 1) 실제 예측 확률
Log Probability \(log(p_i)\) (-∞, 0) 확률의 로그값, 손실 계산에 사용
Cross-Entropy Loss \(L\) ≥ 0 정답 클래스 확률의 음의 로그

8.4 Inference

During inference (sequence generation), the decoder produces the output sequence step-by-step
in an autoregressive manner — meaning each predicted token is fed back as input for the next step.

  • Initialize the decoder state
    • The decoder’s initial hidden state is set to the encoder’s final hidden state:
    • \(h_0^{dec} = h_T^{enc}\)
  • Start with a special <SOS> token
    • This token is used as the first input to signal the beginning of generation.
  • Iterative decoding
    • For each time step t
    • Compute the new hidden state using the previous hidden state and input token:
    • \(h_t = f(h_{t-1}, x_t)\)
    • Generate the output probability distribution over the vocabulary:
    • \(P(y_t) = \text{softmax}(W_o h_t + b_o)\)
    • Select the next token:
      • Greedy decoding: choose the most probable token
      • \(y_t = \arg\max P(y_t)\)
    • Feed the predicted token y_t back into the decoder as input for the next step.
  • Termination
    • The generation stops when the model outputs an <EOS> token
    • or when a predefined maximum length is reached.

8.4.1 Example

  • Seq2Seq (no-attention) — Protein secondary-structure tagging (H: helix, E: strand, C: coil)

  • Task: Amino-acid sequence → per-residue labels {H: helix, E: strand, C: coil}

    • Synthetic, biologically-plausible toy dataset (helix/strand segments embedded)
    • No attention
    • Masked cross-entropy

  • Can upgrade to attention or CRF for longer-range patterns (e.g., motifs).

# ------------------------------
# Simple synthetic data: sample AA, assign labels by propensities + small noise
# ------------------------------
HELICAL = set(list("ALMQEKRH"))
BETA    = set(list("VIYFWTC"))
COIL    = set(list("PGSN"))

def gen_sample(min_len=60, max_len=120, noise=0.5):
    L = random.randint(min_len, max_len)
    seq = [random.choice(AA) for _ in range(L)]
    labels = []
    for a in seq:
        if a in HELICAL: y = "H"
        elif a in BETA:  y = "E"
        else:            y = "C"
        if random.random() < noise:  # flip with small prob
            y = random.choice(["H","E","C"])
        labels.append(y)
    src_ids = [BOS_SRC] + [src_stoi[c] for c in seq] + [EOS_SRC]
    lbl_ids = [lbl_stoi[c] for c in labels]
    return src_ids, lbl_ids

class ProteinSSDataset(Dataset):
    def __init__(self, n):
        self.items = [gen_sample() for _ in range(n)]
    def __len__(self): return len(self.items)
    def __getitem__(self, i): return self.items[i]

def collate_fn(batch):
    srcs, lbls = zip(*batch)
    B, Smax = len(batch), max(len(s) for s in srcs)
    Lmax = max(len(y) for y in lbls)
    src_pad = torch.full((B,Smax), PAD_SRC, dtype=torch.long)
    lbl_pad = torch.full((B,Lmax), PAD_LBL, dtype=torch.long)
    mask    = torch.zeros((B,Lmax), dtype=torch.bool)
    for i,(s,y) in enumerate(batch):
        src_pad[i,:len(s)] = torch.tensor(s)
        lbl_pad[i,:len(y)] = torch.tensor(y)
        mask[i,:len(y)] = 1
    return src_pad.to(device), lbl_pad.to(device), mask.to(device)

8.4.2 Model and Data



# ------------------------------
# Model: BiGRU tagger (no attention)
# ------------------------------
class Tagger(nn.Module):
    def __init__(self, vocab, n_labels, emb=128, hid=256):
        super().__init__()
        self.emb = nn.Embedding(vocab, emb, padding_idx=PAD_SRC) # vocab = 23
        self.rnn = nn.GRU(emb, hid, batch_first=True, bidirectional=True)
        self.proj = nn.Linear(hid*2, n_labels)
    def forward(self, src_ids):
        x = self.emb(src_ids)                 # (Batchsize,Seq_len,Emb_dim)
        y, _ = self.rnn(x)                    # (Batchsize,Seq_len,2*Hidden_dim)
        y = y[:,1:-1,:]                       # strip BOS/EOS → (Batchsize,Seq_len,2*Hidden_dim)
        return self.proj(y)                   # (Batchsize,Seq_len,Num_labels)

# ------------------------------
# Loss & metric
# ------------------------------

def seq_ce(logits, targets, mask):
    B,L,C = logits.shape
    loss = nn.functional.cross_entropy(logits.reshape(B*L,C), targets.reshape(B*L), reduction='none')
    return (loss * mask.reshape(B*L).float()).sum() / mask.sum().clamp(min=1)

def token_acc(logits, targets, mask):
    pred = logits.argmax(-1)
    correct = ((pred==targets) & mask).sum().item()
    return correct / max(1, mask.sum().item())

# ------------------------------
# Data (train/valid/test for evaluation + separate inference sample)
# ------------------------------
N_TRAIN, N_VALID, N_TEST = 1000, 200, 200
BATCH_SIZE, EPOCHS = 64, 5
train_loader = DataLoader(ProteinSSDataset(N_TRAIN), batch_size=BATCH_SIZE, shuffle=True,  collate_fn=collate_fn)
valid_loader = DataLoader(ProteinSSDataset(N_VALID), batch_size=BATCH_SIZE, shuffle=False, collate_fn=collate_fn)
test_loader  = DataLoader(ProteinSSDataset(N_TEST),  batch_size=BATCH_SIZE, shuffle=False, collate_fn=collate_fn)

8.4.3 Training


# ------------------------------
# Train
# ------------------------------
model = Tagger(len(SRC_TOKENS), len(LBLS)).to(device)
opt = torch.optim.AdamW(model.parameters(), lr=2e-3)
for ep in range(1, EPOCHS+1):
    model.train(); tot=0
    for src,y,m in train_loader:
        opt.zero_grad(); logits = model(src); loss = seq_ce(logits,y,m)
        loss.backward(); nn.utils.clip_grad_norm_(model.parameters(),1.0); opt.step()
        tot += loss.item()
    # valid
    model.eval(); vloss=vacc=0; steps=0
    with torch.no_grad():
        for src,y,m in valid_loader:
            logits = model(src)
            vloss += seq_ce(logits,y,m).item()
            vacc  += token_acc(logits,y,m); steps+=1
    print(f"Epoch {ep}: train {tot/len(train_loader):.3f} | valid {vloss/steps:.3f}, acc {vacc/steps*100:.2f}%")

# ------------------------------
# Evaluation metrics & plots (on TEST set)
# ------------------------------
@torch.no_grad()
def collect_probs_labels(model, loader):
    """Return flattened probs & labels for valid (non-pad) tokens.
       P: (N_tokens, C), Y: (N_tokens,)
    """
    model.eval()
    probs_all, y_all = [], []
    for src, y, m in loader:
        logits = model(src)               # (B, L, C)
        probs  = logits.softmax(-1).cpu() # (B, L, C)
        mask   = m.cpu().bool()           # (B, L)
        probs_all.append(probs[mask])     # (n_i, C)
        y_all.append(y.cpu()[mask])       # (n_i,)
    P = torch.cat(probs_all, dim=0)       # (N, C)
    Y = torch.cat(y_all, dim=0)           # (N,)
    return P, Y


def confusion_matrix_from_preds(pred, true, num_classes):
    """Rows=true, Cols=pred; returns numpy (C x C)."""
    p = pred.numpy(); t = true.numpy()
    cm = np.zeros((num_classes, num_classes), dtype=np.int64)
    for ti, pi in zip(t, p):
        cm[ti, pi] += 1
    return cm


def prf_from_cm(cm, label_indices):
    metrics = {}
    TP_m = FP_m = FN_m = 0
    for c in label_indices:
        tp = cm[c, c]
        fp = cm[:, c].sum() - tp
        fn = cm[c, :].sum() - tp
        prec = tp / (tp + fp + 1e-12)
        rec  = tp / (tp + fn + 1e-12)
        f1   = 2 * prec * rec / (prec + rec + 1e-12)
        metrics[c] = dict(precision=prec, recall=rec, f1=f1, support=int(cm[c,:].sum()))
        TP_m += tp; FP_m += fp; FN_m += fn
    macro = (
        np.mean([metrics[c]['precision'] for c in label_indices]),
        np.mean([metrics[c]['recall']    for c in label_indices]),
        np.mean([metrics[c]['f1']        for c in label_indices]),
    )
    micro_p = TP_m / (TP_m + FP_m + 1e-12)
    micro_r = TP_m / (TP_m + FN_m + 1e-12)
    micro_f = 2 * micro_p * micro_r / (micro_p + micro_r + 1e-12)
    return metrics, dict(macro=macro, micro=(micro_p, micro_r, micro_f))


def precision_recall_curve_binary(scores: np.ndarray, y_true: np.ndarray):
    order = np.argsort(-scores)
    y_sorted = y_true[order]
    tp = np.cumsum(y_sorted == 1)
    fp = np.cumsum(y_sorted == 0)
    positives = (y_true == 1).sum()
    precision = tp / np.maximum(tp + fp, 1)
    recall = tp / np.maximum(positives, 1)
    return precision, recall


def auprc(precision: np.ndarray, recall: np.ndarray):
    order = np.argsort(recall)
    r = recall[order]; p = precision[order]
    return np.trapz(p, r)
